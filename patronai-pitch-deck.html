03 · Architectural Breakthrough

The Deterministic Trust Layer

"A rule a prompt can hallucinate around is not a financial rule."

🧠 Probabilistic Layer Google Gemini
  • Multimodal Vision OCR reads messy VAT invoices & receipts.
  • Extracts Merchant Tax ID (NIP), line items, and gross totals.
  • Audits semantic match vs. declared club purpose.
  • Output is advisory JSON only — never writes the ledger.
⚙️ Deterministic Layer Plain Code & Postgres
  • SHA-256 cryptographic hashes seal each verified allocation.
  • Neon Serverless PostgreSQL enforces ACID relational constraints.
  • v_ledger_totals view computes live multi-currency totals.
  • Governs all money, balances, and immutable certificates.
Auditable AI: mathematical proofs safeguard against hallucination in financial transactions.
